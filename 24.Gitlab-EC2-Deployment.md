## 🧩 **Scenario**

You have:

* A simple web app (e.g., HTML or Node.js).
* An EC2 instance running Amazon Linux (or Ubuntu).
* SSH access using a `.pem` key.
* GitLab repository containing your app code.

Goal:

> On every push to the main branch, deploy the latest code to the EC2 instance.

---

## ⚙️ **Step 1: Prepare your EC2 instance**

On your EC2:

```bash
sudo yum install git -y    # or apt install git
mkdir /var/www/myapp
cd /var/www/myapp
```

Create a deploy user or use `ec2-user` and enable SSH access.

---

## 🔑 **Step 2: Add SSH Key to GitLab**

1. In GitLab → **Settings → CI/CD → Variables**
2. Add the following **protected variables**:

   * `EC2_HOST` → your EC2 public IP (e.g., `13.233.xx.xx`)
   * `EC2_USER` → e.g., `ec2-user`
   * `SSH_PRIVATE_KEY` → contents of your `.pem` file

---

## 🚀 **Step 3: GitLab CI/CD Pipeline (`.gitlab-ci.yml`)**

```yaml
stages:
  - deploy

deploy_to_ec2:
  stage: deploy
  image: alpine:latest
  before_script:
    # Install SSH client
    - apk add --no-cache openssh
    # Configure SSH key
    - mkdir -p ~/.ssh
    - echo "$SSH_PRIVATE_KEY" > ~/.ssh/id_rsa
    - chmod 600 ~/.ssh/id_rsa
    # Avoid host verification prompt
    - echo -e "Host *\n\tStrictHostKeyChecking no\n" > ~/.ssh/config
  script:
    - echo "Deploying to EC2..."
    # Copy app files to EC2 (adjust target directory)
    - scp -r ./ $EC2_USER@$EC2_HOST:/var/www/myapp/
    # Optionally restart service or app
    - ssh $EC2_USER@$EC2_HOST "sudo systemctl restart myapp || echo 'No service to restart'"
  only:
    - main
```

---

## 🧠 **How it Works**

1. When you push to `main` branch:

   * GitLab runner starts the `deploy_to_ec2` job.
2. SSH key is configured dynamically (no hardcoding).
3. Files are copied to your EC2 instance using `scp`.
4. Optionally restarts your app or service.

---

## 💡 **Optional Enhancements**

| Task                  | How                                                                                |
| --------------------- | ---------------------------------------------------------------------------------- |
| Deploy Node.js app    | `ssh $EC2_USER@$EC2_HOST "cd /var/www/myapp && npm install && pm2 restart app.js"` |
| Deploy Docker app     | `ssh $EC2_USER@$EC2_HOST "docker pull <image> && docker run -d <container>"`       |
| Blue-Green deployment | Use two directories `/var/www/app_v1` and `/var/www/app_v2`                        |

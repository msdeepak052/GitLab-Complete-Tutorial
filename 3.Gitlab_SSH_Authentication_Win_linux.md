# **GitLab SSH authentication** 🔐 step-by-step for **both Windows** and **Linux**
---

## 🚀 **1️⃣ Overview: How SSH Authentication Works**

GitLab uses **SSH keys** to securely identify your system.
Once configured:

* You **generate an SSH key pair** → a **private key** (kept locally) and a **public key** (added to GitLab).
* Git uses this key pair for authentication instead of a password or token.

---

## 🪟 **2️⃣ Windows: GitLab SSH Setup**

### **Step 1: Install Git**

Install from:
👉 [https://git-scm.com/downloads](https://git-scm.com/downloads)
Make sure you can open **Git Bash**.

---

### **Step 2: Generate SSH Key Pair**

Open **Git Bash** and run:

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

> If you get an error about `ed25519` not supported, use:

```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

* When prompted for a file location, press **Enter** (default: `C:\Users\<username>\.ssh\id_ed25519`)
* Optionally set a **passphrase** (recommended for security)

---

### **Step 3: Start the SSH Agent**

In **Git Bash**, run:

```bash
eval "$(ssh-agent -s)"
```

Add your private key:

```bash
ssh-add ~/.ssh/id_ed25519
```

If you used `rsa`:

```bash
ssh-add ~/.ssh/id_rsa
```

---

### **Step 4: Copy the Public Key**

Run:

```bash
cat ~/.ssh/id_ed25519.pub
```

Copy the entire output (starts with `ssh-ed25519` or `ssh-rsa`).

---

### **Step 5: Add SSH Key to GitLab**

1. Log in to your GitLab account.
2. Go to:
   **User Profile → Preferences → SSH Keys**
   or directly visit 👉 `https://gitlab.com/-/profile/keys`
3. Paste the public key into the box.
4. Give it a **title** (like `Windows-Laptop`) and set an **expiry date** (optional).
5. Click **Add key**.

---

### **Step 6: Test the Connection**

Run:

```bash
ssh -T git@gitlab.com
```

Expected output:

```
Welcome to GitLab, @deepak!
```

If you see a message like “Are you sure you want to continue connecting?”, type `yes`.

---

### **Step 7: Use SSH URL for Repositories**

When cloning:

```bash
git clone git@gitlab.com:username/repository.git
```

Check your remote:

```bash
git remote -v
```

If HTTPS is set, change it to SSH:

```bash
git remote set-url origin git@gitlab.com:username/repository.git
```

✅ Done! You can now push/pull without typing a password.

---

## 🐧 **3️⃣ Linux: GitLab SSH Setup**

### **Step 1: Check for Existing SSH Keys**

```bash
ls -al ~/.ssh
```

If you see files like `id_ed25519` or `id_rsa`, you already have keys.

---

### **Step 2: Generate a New SSH Key**

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

Press **Enter** for defaults and optionally add a passphrase.

---

### **Step 3: Start ssh-agent and Add Key**

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

---

### **Step 4: Copy Public Key**

```bash
cat ~/.ssh/id_ed25519.pub
```

Copy the key output.

---

### **Step 5: Add to GitLab**

Go to
👉 **User → Preferences → SSH Keys**
Paste your key, give a title, and click **Add key**.

---

### **Step 6: Test SSH Connection**

```bash
ssh -T git@gitlab.com
```

You should see:

```
Welcome to GitLab, @deepak!
```

---

### **Step 7: Use SSH Repository URL**

Clone or set remote using SSH:

```bash
git clone git@gitlab.com:username/repository.git
```

Check and modify remote if needed:

```bash
git remote -v
git remote set-url origin git@gitlab.com:username/repository.git
```

---

## ✅ **4️⃣ Verify SSH Configuration**

To confirm which key is being used:

```bash
ssh -vT git@gitlab.com
```

You should see a line like:

```
Offering public key: /home/deepak/.ssh/id_ed25519
```

---

## ⚙️ **5️⃣ Optional: Multiple SSH Keys (if you use multiple GitLab or GitHub accounts)**

Edit your SSH config file:

```bash
nano ~/.ssh/config
```

Add:

```bash
Host gitlab.com
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_ed25519
```

If you have multiple accounts, you can use custom host aliases:

```bash
Host gitlab-work
  HostName gitlab.com
  User git
  IdentityFile ~/.ssh/id_gitlab_work
```

Then clone using:

```bash
git clone gitlab-work:username/repo.git
```

## ⚠️ **6️⃣ Troubleshooting**

| Issue                           | Reason                           | Fix                                                          |
| ------------------------------- | -------------------------------- | ------------------------------------------------------------ |
| `Permission denied (publickey)` | Wrong key or not added to GitLab | Add correct public key                                       |
| SSH key not loaded              | ssh-agent not running            | Run `eval "$(ssh-agent -s)"` and `ssh-add ~/.ssh/id_ed25519` |
| Old HTTPS remote still set      | Using HTTPS URL                  | Use `git remote set-url origin git@...`                      |
| Firewall blocks SSH (port 22)   | Network restriction              | Use HTTPS instead                                            |
